Upload Photo to Stylize

Instructions

  • Select 1-5 images using the file picker (hold SHIFT while selecting)
  • Click "Stylize Images" to convert to Ghibli-style.
  • Each result will show with its own download button.

After Styling

  • FIRST TIMER hit allow multiple downloads
  • Preview all photos to check for errors
  • Select "Download All" — it will appear in your DOWNLOAD tab on Darkroom
